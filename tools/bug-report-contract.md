# Приёмник отчётов FlowBar

Адрес приёмника задаётся в `BugReportUrl` в файле `FlowBar.BugReport.cs`. Для демосборки адрес можно передать в переменной окружения `FLOWBAR_REPORT_URL`. Форма открывается через «Настройки → Общие → Данные → Сообщить об ошибке».

Клиент отправляет HTTPS POST с JSON в UTF-8, размер тела до 32 КиБ.

```json
{
  "report_id": "92a70b2197de4904b2d6932544f27840",
  "version": "1.6.11a",
  "description": "Что произошло и как это повторить",
  "report": "Диагностика. Пустая строка, если пользователь снял флажок."
}
```

После подтверждённой доставки сервер возвращает HTTP 200 и то же значение `report_id`.

```json
{"ok":true,"report_id":"92a70b2197de4904b2d6932544f27840"}
```

Повтор той же отправки использует тот же идентификатор. Приёмник может вернуть сохранённое подтверждение, чтобы избежать повторного сообщения. При ограничении частоты сервер возвращает HTTP 429. Токен Telegram, номер чата и результат вызова Telegram остаются на сервере.
